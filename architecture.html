Majstro Application Architecture

Majstro turns an Android tablet into a living-room classical music quiz host (like Jackbox). Players join on their phones over Wi-Fi, the tablet plays music via Spotify Connect (or offline Demo Mode), and one central game engine keeps every screen in sync.

1. The Tablet = Host Screen
Displays the QR code, current clue, answer reveal, composer portrait, and scoreboard.
2. Phones = Controllers
Players scan the QR code to open a web page hosted directly by the tablet—no app install needed.
3. One Brain in the Middle
A single game engine (QuizEngine) tracks scores and rounds, pushing live updates to the tablet and all phones at once.

2. Architectural Layers & Key Modules

Domain Core Pure Kotlin
  • QuizEngine: Mutex-guarded state machine exposing StateFlow<GameState>; handles player registration, lobby config, scoring, and round transitions.
  • Ports.kt: Defines RepertoireSource, QuestionGenerator, and MusicPlayerGateway.
  • Models.kt: Immutable data models — ClassicalWork, QuizQuestion, Player, WrittenAnswer, RoundAward, PlaybackStatus, and GameState.
Data & Question Generation Adapters
  • InMemoryRepertoireSource: Curated 25-work classical repertoire across 5 difficulty levels (5 works per level) with composition years and stylistic clues.
  • DefaultQuestionGenerator: Selects works nearest to the target difficulty and builds 4-option prompts across QuestionCategory values.
Playback & Spotify Auth Deep Module
  • SpotifySession: Implements both MusicPlayerGateway and SpotifyAuthSession.
  • Owns OAuth 2.0 PKCE setup, token refresh/persistence via SpotifyAuthStore & SharedPrefsKeyValueStore, Spotify Connect playback, and zero-config Demo Mode fallback.
Embedded LAN Server Ktor CIO :8080
  • KtorControllerServer: Hosts the Jackbox-style mobile web controller on the Tablet's LAN IP.
  • Pushes PhoneGameState snapshots over WS /ws whenever QuizEngine.state changes, and routes phone commands back to QuizEngine.
  • Serves /spotify for phone-based Spotify Client ID & OAuth PKCE linking.
Tablet Host UI Jetpack Compose
  • MainActivity: Edge-to-edge immersive host activity wiring dependencies and resolving the LAN IPv4 address.
  • MajstroTvApp: Collects engine.state and animates between LobbyScreen, QuestionScreen, RevealScreen, and GameOverScreen.
  • QrCodeBitmap & SpotifySetupDialog: ZXing QR generation for instant phone join and Spotify setup.

3. Quiz Match Lifecycle

1. LOBBY
Players join via QR/LAN URL; host sets round count (1–25), difficulty (1–5), and mode (WRITE_IN or MULTIPLE_CHOICE).
→
2. QUESTION
MusicPlayerGateway.play() starts audio; players submit multiple-choice picks or free-text Composer, Piece, and Year guesses.
→
3. REVEAL
Auto-scores Multiple Choice (+2) or pre-selects Closest Year (+1) in Write-In mode with live manual judging toggles (+1 Composer, +2 Piece).
→
4. GAME_OVER
Displays sorted final leaderboard with options to play again or return to Lobby keeping connected players.
